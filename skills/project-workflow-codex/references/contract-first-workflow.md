# Contract-First Workflow

Codex generates a contract from Phase 0-2 evidence. Claude Code reviews the contract in Phase 3. Codex triages the review and produces a revised contract when needed. Claude Code executes only after the contract is approved and the user approves execution.

Contract versions:

```text
v1: generated by Codex from discovery and clarity
v2+: generated by Codex after Claude Phase 3 findings
approved: final contract allowed to execute
```

Never skip:

```text
Codex preflight
Claude Phase 3 review
Codex review triage
user execution approval
Codex final audit
```
